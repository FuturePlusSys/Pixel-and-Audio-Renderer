Downloads and stores files under C:\Users\"username"\Documents\FuturePlus\FS4500

This app is meant to be used with the FS4500 Probe Manager. The FS4500 must be open (online or offline mode) and have captured data in order to work.

If using the DSC setting, a file must be changed in this directory, "test.cfg" the user must:
  -Open test.cfg file using notepad or notepad++
  -Find line that starts with SRC_LIST
  -Change {username} within the path to the username of the current user.
